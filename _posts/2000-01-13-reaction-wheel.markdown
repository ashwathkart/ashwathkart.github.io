## Reaction Wheel Pendulum Control using Learning-Assisted Control Strategies

### Hardware

* Arduino Uno Q - usually you would need a Microcontroller and a Microprocessor, people would usually use a Raspberry Pi and then an Arduino in series to do this, but Arduino has made this cool product called the Uno Q which has both a MCU and an MPU and they communciate over an API bridge

### Idea

* I want to do a bit of this thing called learning assisted control - LQR, which is like u make a vague controller and then you tune the parameters better with a machine learning algorithm, not sure how it will end up but it'll be a fun project i guess
